# 버스 정류장 지도 상세 규격

[기준 PNG · 1024 × 1536](bus-map-design-2026-11-13.png) · [화면 구성](bus-map-design-2026-11-13.md)

## 기준 도로 폭

첨부 원본에서 서면역 북쪽으로 이어지는 노란 도로의 직선 구간을 기준으로 삼는다. 왼쪽 위가 (0, 0)일 때 y=460에서 왼쪽 외곽선 중심 x=75, 오른쪽 외곽선 중심 x=84다. 두 경계 픽셀을 포함한 **10 px를 도로 폭 100%**로 정한다. 단면 구성은 외곽선 약 1 px + 내부 약 8 px + 외곽선 약 1 px다.

렌더링할 때는 현재 화면에서 이 도로 등급에 적용한 보정 폭을 W로 둔다. 모든 지도 심볼과 이름은 **W × 표의 비율 ÷ 100**으로 계산한다. 같은 화면에서는 골목 안의 정류장도 같은 W를 사용한다. 예를 들어 W=5 화면 px이면 원본에서 28 px인 마커는 14 화면 px이다. 원본 한 장으로 판별 가능한 도로 위계는 노란 주요 도로와 흰 일반 도로다. 고속도로 여부와 줌 단계별 실제 폭은 도로 데이터와 지도 축척으로 결정한다.

## 색상

좌표는 원본 PNG 픽셀 위치이며 HEX는 해당 지점의 RGB 값이다. 노선과 마커에도 미세한 색 변화가 있어 단색 요소를 그릴 때는 아래 내부 표본을 사용한다. 공원처럼 면 안에서 색이 달라지는 요소는 위치별 색을 유지한다.

| 요소 | 원본 색과 표본 좌표 |
|---|---|
| 노란 주요 도로 | 내부 `#FFF3AF` (80,460), 왼쪽 경계 `#FAD75A` (75,460), 오른쪽 경계 `#FED752` (84,460) |
| 일반 도로와 시가지 | 흰 도로망, 옅은 회청색 블록. 기준 도로 인접 배경 `#E9EDF2` (72,460), `#F6F6F8` (90,460) |
| 공원·산지 | 시청공원 `#D3F0C8` (360,570), 금련산 `#CBEDBD` (900,330) |
| 바다 | `#8ED9FE` (880,860) |
| 선택 노선 | 파란 선 `#046EFD` (580,560), 경유 지점은 흰 중심과 파란 테두리 |
| 버스정류장 | 일반 배지 `#048C71` (238,286), 선택 핀 `#FA620E` (529,494). 흰 버스 그림과 흰 외곽선 |
| 시청·학교 | 관공서 기둥 `#637792` (104,248), 학사모 `#637998` (516,711) |
| 산·공원 | 산봉우리 `#3E6E47` (903,280), 나무 `#3DA03E` (359,586) |
| 쇼핑·해변 | 쇼핑백 `#0978FF` (156,657), 파라솔 `#0D75EA` (833,799) |
| 행정구역명 | 연산동 글자 `#565D67` (310,365) |

## 랜드마크·POI·정류장 크기

각 크기는 지도에서 보이는 **유색 도형의 가로 × 세로**다. 흰 후광과 그림자를 제외한 픽셀 경계의 근삿값이다. 제작할 때는 각 그림의 가로세로 비율을 유지한다.

| 요소 | 원본 px | 도로 폭 대비 가로 × 세로 |
|---|---:|---:|
| 부산시청 · 기둥 건물 | 36 × 34 | 360% × 340% |
| 부산여자상업고 · 학사모 | 34 × 27 | 340% × 270% |
| 금련산 · 산봉우리 | 28 × 23 | 280% × 230% |
| 서면 롯데백화점 · 쇼핑백 | 26 × 31 | 260% × 310% |
| 광안리해수욕장 · 파라솔 | 32 × 32 | 320% × 320% |
| 일반 정류장 · 청록 원형 배지 | 27 × 28 | 약 280% 지름 |
| 선택 정류장 · 주황 핀, 꼬리 포함 | 56 × 65 | 560% × 650% |
| 선택 정류장 말풍선 안 버스 배지 | 41 × 40 | 약 400% 한 변 |

선택 핀의 꼬리 끝을 노선 위 주황 지점에 맞춘다. 일반 정류장은 청록 원의 중심을 정류장 위치에 둔다. 지도 위 장소명은 아이콘 아래에 가운데 정렬하며, 서면 롯데백화점처럼 긴 이름은 두 줄로 배치한다.

## 글자 크기

PNG에서 읽을 수 있는 값은 **렌더링된 글자의 잉크 높이**다. 아래 비율을 목표로 실제 사용할 한글 폰트의 크기를 맞춘다. 예를 들어 W=5 px에서 부산시청 글자가 10 px 높이로 보여야 한다. 폰트 설정값은 같은 문자열을 렌더링해 이 높이에 맞춘다.

| 구분 | 측정 문자열 | 원본 글자 높이 | 도로 폭 대비 목표 높이 |
|---|---|---:|---:|
| 랜드마크 이름 | 부산시청 / 부산여자상업고 | 20 / 19 px | 200% / 190% |
| 일반 POI 이름 | 서면 / 시청공원 / 광안리해수욕장 | 각 20 px | 200% |
| 동 이름 | 연산동 | 24 px | 240% |
| 구 이름 | 연제구 | 29 px | 290% |
| 도로명 | 시안에 판독 가능한 도로명 없음 | 미측정 | 기준 화면에서는 생략 |

랜드마크와 POI는 진한 글자에 얇은 흰 후광을 두고, 행정구역명은 회색으로 표시한다. 흰 후광은 위 글자 높이에서 제외한다. 전체 지도를 원본과 비교할 때는 먼저 주요 도로 폭을 맞춘 뒤, 같은 화면에서 일반 정류장 지름이 그 폭의 약 2.8배이고 장소명 한 줄 높이가 약 2배인지 확인한다.
