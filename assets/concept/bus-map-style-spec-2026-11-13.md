# 버스 지도 스타일 상세 규격 (2026-11-13)

> 대상: [버스 정류장 지도 UI 시안](bus-map-design-2026-11-13.md)  
> 목적: 시안의 분위기를 지도 렌더링·아이콘 제작에 적용할 수 있도록 색상, 선폭, 아이콘 크기, 글자 크기로 구체화한다.  
> 단위: 별도 표기가 없으면 MapLibre 스타일 기준 CSS px. 도로 폭은 외곽선(casing)과 내부선(fill)을 함께 그리는 2중 선 기준이다. 줌 보간값 사이의 값은 선형 보간한다.

## 1. 스타일 원칙

- 지도 바탕은 밝고 채도가 낮게 유지한다. 정류장, 선택 노선, 현재 선택 상태가 지도 배경보다 먼저 읽혀야 한다.
- 도로는 등급별 폭과 온도 차이로 위계를 표현한다. 도로 등급 색은 베이지 계열, 일반 도로는 흰색 계열로 정리한다.
- 공원·녹지는 연한 민트 그린, 물은 옅은 하늘색으로 표현한다.
- 시안의 파란 노선은 선택된 노선에만 사용한다. 일반 도로 색이나 정류장 기본색으로 재사용하지 않는다.
- 한글 이름을 우선 사용하고 이름이 없을 때만 기본 이름으로 대체한다.
- 실운영 데이터가 없는 POI, 정류장, 노선, 도착시간을 지도에 임의로 만들어 표시하지 않는다.

## 3. 도로 크기·넓이

아래 폭은 줌 레벨에 따라 변화한다. 표의 값은 `외곽선 / 내부선` 순서이며, 외곽선이 내부선보다 넓어 양쪽에 일정한 테두리가 보이도록 한다.

| 도로 분류 | 데이터 class | 색상 | z10 | z14 | z17 |
|---|---|---|---:|---:|---:|
| 고속도로·도시고속도로 | `motorway`, `trunk` | 베이지 | 1.4 / 1.0 px | 7.3 / 6.0 px | 20 / 18.5 px |
| 주요 간선도로 | `primary`, `secondary` | 웜 화이트 | 1.2 / 0.8 px | 5.8 / 4.8 px | 17 / 15.4 px |
| 보조 간선도로 | `tertiary` | 화이트 | z11부터 | 3.8 / 2.7 px | 12 / 10.4 px |
| 생활·골목도로 | `residential`, `minor`, `service` | 화이트 | z11부터 | 2.5 / 1.8 px | 9.5 / 8.1 px |
| 보행로 | `path`, `footway`, `pedestrian` | 회청색 | 숨김 | z15부터 | 1.7 px |

### 도로 표시 규칙

- 선 끝과 교차점은 round cap·round join을 사용한다.
- 고속도로와 주요 간선은 동네 골목보다 먼저 읽히도록 한다. 지도 전체에 도로명이 과도하게 반복되지 않게 배치한다.
- 고속도로 분기·램프는 원본 벡터 타일 형상을 따른다. 단순화한 직선이나 장식용 분기선을 추가하지 않는다.
- z10 미만은 도로 세부 선폭을 축소하고 동네 도로를 숨긴다. z10~11에는 광역 간선 위주, z11부터 동네 도로를 표시한다.
- 도로 선폭은 스타일의 렌더링 픽셀 값이다. 실제 지상의 도로 폭이나 거리로 해석하지 않는다.

## 4. 공원·녹지 크기 기준

공원은 폴리곤 면으로 표현하며 아이콘으로 대체하지 않는다.

| 요소 | 기준 |
|---|---|
| 공원 면 색상 | `#CFEBD5`, 불투명도 94% |
| 잔디·자연 녹지 | `#E2F1E3`, 불투명도 90% |
| 공원 이름 노출 | z15부터 |
| 공원 이름 크기 | z15: 10 px → z17: 11.5 px |
| 공원 경계선 | 기본 미표시. 인접한 면 구분이 어려운 경우에만 1 px `#B8DCC2` |
| 작은 녹지 | 지도 축척에서 읽히지 않을 정도로 작으면 면만 표시하고 이름·아이콘은 생략 |

공원 폴리곤을 도로보다 위에 그리지 않는다. 공원 이름은 폴리곤 내부에서 배치하고 도로명·정류장명과 겹치면 하나를 생략한다.

## 5. POI 및 랜드마크 아이콘 크기

아이콘 크기는 화면상 지름 기준이다. 픽셀 아트나 이모지 대신 같은 선 굵기의 벡터 아이콘(SVG 등)을 사용한다. 기본 실루엣은 단순하게 유지하고 작은 크기에서도 구분 가능하도록 내부 세부선을 최소화한다.

| 아이콘 종류 | 표시 시작 | 기본 크기 | 강조 크기 | 스타일 |
|---|---:|---:|---:|---|
| 일반 POI | z15 | 16 × 16 px | 20 × 20 px | 청록 단색 선/면 아이콘 |
| 랜드마크 | z14 | 22 × 22 px | 28 × 28 px | 장소 성격이 구분되는 단색 아이콘 |
| 버스 정류장 마커 | z12 | 지름 24 px | 선택 시 지름 34 px | 청록 원+흰 버스, 선택 시 주황 원+흰 버스 |
| 사용자 현재 위치 점 | 위치 권한이 있을 때만 | 점 12 px + 정확도 링 | 고정 | 파란 점과 반투명 파란 정확도 원 |

### 아이콘 여백과 배치

- POI·랜드마크 심볼은 아이콘 경계에서 최소 4 px의 시각 여백을 둔다.
- 아이콘+라벨 그룹 사이에는 최소 4 px를 둔다.
- 마커와 정류장 이름 카드가 겹치면 카드가 우선한다. 선택된 장소는 다른 POI보다 위에 그린다.
- 같은 위치에 여러 POI가 있으면 겹쳐 쌓지 말고 우선순위가 높은 하나를 표시하거나 군집으로 묶는다.
- 랜드마크는 공원, 학교, 대학, 시청, 역, 버스터미널, 병원 등 길찾기에 도움이 되는 시설로 제한한다. 일반 상점·음식점 POI는 기본 지도에서 생략한다.
- POI 아이콘에는 원형 배경을 기본으로 붙이지 않는다. 터치 가능한 선택 상태에만 흰색 원형 바탕 또는 작은 그림자를 허용한다.
- 정류장 마커 크기는 기존 구현 문서의 축척별 원형 마커 반경(기본 3.2~5.1 px)과 구별되는 시안형 버스 배지 기준이다. 실제로 두 종류를 함께 노출할 경우 같은 정류장을 중복 표시하지 않는다.

## 6. 글자 크기·색상

글자 크기는 MapLibre symbol `text-size`의 px 단위다.

| 텍스트 | 표시 시작 | 글자 크기 | 색상 | 후광·외곽 |
|---|---:|---:|---|---|
| 시·구·동 이름 | z8 | z8 11 px → z12 12 px → z15 13.5 px → z17 14 px | `#465A71` | 바탕색 `#F7F9FC`, 1.65 px |
| 랜드마크 이름 | z15 | z15 10 px → z17 11.5 px | `#62778C` | 흰색, 1.3 px |
| 공원 이름 | z15 | z15 10 px → z17 11.5 px | `#62778C` | 흰색, 1.3 px |
| POI 이름 | z16 | z16 10 px → z18 11 px | `#62778C` | 흰색, 1.3 px |
| 도로명 | z15 | 10.5 px | `#8A96A4` | 흰색, 1.15 px |
| 정류장 이름 카드 | 선택 시 | 12 px, 최대 2줄 | `#263746` | 흰색 카드 |
| 정류장 번호 | z16 | 10 px | `#465A71` | 흰색 후광 1 px |
| 노선 번호 칩 | 선택 시 | 12 px medium | 흰색/딥 틸 | 칩 배경으로 대비 확보 |

### 텍스트 배치

- 이름은 `name:ko`가 있으면 우선 사용하고 없으면 `name`을 사용한다.
- 도로명은 도로를 따라 배치한다. 도로가 짧거나 곡률이 급한 구간에서는 생략한다.
- POI·랜드마크 라벨은 최대 폭 8~9 em, 줄 간격은 글자 크기의 1.2배로 한다.
- 기본 지도 라벨은 겹침을 허용하지 않는다. 중요도 순서는 선택 정류장 → 랜드마크 → 지역명 → 도로명 → 일반 POI다.
- 지도 배경이 복잡한 곳에는 얇은 밝은 후광을 사용한다. 진한 테두리나 큰 그림자로 지도 위젯처럼 보이게 하지 않는다.
- 정류장 카드와 도착정보 바텀시트 내부의 앱 UI 글자는 이 지도 라벨 기준을 따르지 않고 각 화면 컴포넌트 토큰을 따른다.

## 7. 확대 단계별 표시 요약

| 줌 | 지도 표현 |
|---|---|
| z10 미만 | 기본 지형, 물, 공원, 고속도로·주요 간선. POI와 정류장 이름은 숨김 |
| z10–11 | 보조 간선 추가 |
| z12–14 | 생활 도로 및 정류장 마커 표시. 랜드마크 아이콘은 z14부터 |
| z15 | 보행로, 도로명, 공원·랜드마크 이름, 일반 POI 아이콘 |
| z16 이상 | POI 이름과 정류장 번호 표시. 화면 혼잡 시 우선순위 낮은 항목 생략 |

## 8. 구현 및 검수 체크리스트

- 도로 폭은 casing/fill 페어를 유지하고 표의 줌 값 사이에서 부드럽게 보간한다.
- 고속도로·간선·일반도로의 색과 선폭이 한 단계씩 구분되는지 확인한다.
- 흰색 도로 내부선이 흰 배경에서 사라지지 않도록 외곽선이 계속 보이는지 확인한다.
- 공원 면은 도로·정류장 마커보다 배경에 머무르고, 수면과 혼동되지 않는지 확인한다.
- POI와 랜드마크 아이콘을 16 px·22 px 크기에서 축소해도 서로 구분할 수 있는지 확인한다.
- 글자는 한국어 기준으로 줄바꿈·겹침을 확인하고, 라벨이 많은 구간에서 우선순위에 따라 숨겨지는지 확인한다.
- 선택 노선은 검증된 경로 형상에만 적용한다. 노선이 없으면 선을 추정하지 않는다.
- 선택하지 않은 정류장/POI가 주황색 선택색을 사용하지 않도록 한다.

## 9. 기준 및 변경 기록

- 기존 지도 렌더링 토큰과 현재 줌별 도로 폭은 `assets/map/bus_transit_style.json`을 기준으로 정리했다.
- 시안에서 명확히 구분되는 청록 정류장, 주황 선택 상태, 파란 노선과 바텀시트 구성은 `assets/concept/bus-map-design-2026-11-13.md`를 따른다.
- POI·랜드마크 아이콘과 라벨의 세부 크기처럼 기존 스타일에 수치가 없는 항목은 이 문서의 신규 제안값이다. 실제 시안 원본에서 측정한 값이라고 간주하지 않는다.
- 문서 작성은 지도 디자인 규격화이며 앱 코드·지도 스타일 JSON 변경은 포함하지 않는다.
