# Bus Timer UI Concept

## 대상 사용자

대중교통으로 출퇴근하는 직장인과 등하교하는 학생을 중심으로 설계합니다. 집·회사·학교 저장 경로, 가는 길/오는 길, 요일별 시간대와 빠른 이동 시작을 우선 배치합니다.

## 현재 디자인 기준

현재 제품 컨셉은 **출발지·목적지 기반 직행/환승 경로 비교와 구간별 도착 5분 전 탑승 알림**입니다. [프로젝트 컨셉 문서](../../docs/PROJECT_CONCEPT.md)를 기능 사양으로 사용합니다.

| 화면 | 새 기획의 목적 |
|---|---|
| 홈 | 출발지·목적지 및 출발 날짜·시간 선택 |
| 경로 비교 | 시간대별 직행·환승, 도착 시각·대기시간·환승 횟수 비교 |
| 경로 상세 | 구간별 버스 선택, 다음 배차, 환승 도보·여유시간 |
| 이동 중 | 현재 구간과 다음 승차/환승 차량 및 지연·대안 안내 |
| 탑승 알림 | 첫 승차와 각 환승 버스의 도착 5분 전 안내 |
| 저장 경로·시간 설정 | 자주 가는 이동과 요일·시간대 관리 |
| 설정 | 알림·위치 권한과 개인정보 안내 |
| 웹 | 출발/목적지 입력과 시간대별 경로 비교 |

아이보리 바탕·딥 틸 기본 동작·라임 알림 강조를 유지합니다. 구간별 타임라인, 목적지 도착 시각, 환승 대기시간을 중심으로 설계하며 실시간 정보와 시간표·배차 추정을 구분합니다.
