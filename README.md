# Bus Stop Timer

출발지와 목적지를 선택하면 직행·환승 버스 경로를 만들고, 출발 시간대별로 실제 탑승 가능한 버스 조합을 비교해 각 승차 구간의 도착 5분 전 알림을 제공하는 프로젝트입니다.

## 대상 사용자

대중교통으로 출퇴근하는 직장인과 등하교하는 학생이 핵심 사용자입니다. 자주 가는 집·회사·학교 경로와 요일별 시간대를 저장하고, 직행·환승의 도착 시각과 대기시간을 비교해 상황에 맞는 버스를 선택하도록 돕습니다.

## 프로젝트 컨셉

- 사용자가 출발지·목적지와 출발 날짜·시간 또는 비교할 시간대를 선택합니다.
- 직행과 환승 경로를 검색하고 각 구간에서 탈 버스를 선택합니다.
- 모든 구간의 실시간 버스 도착 정보, 이동시간, 환승 도보시간 및 다음 차량의 배차간격을 함께 고려합니다.
- 환승 정류장에 도착한 뒤 실제로 탈 수 있는 차량을 기준으로 대기시간과 목적지 도착 시각을 비교합니다.
- 선택한 이동을 시작하면 첫 승차와 각 환승 구간에서 탈 버스의 도착 5분 전에 알립니다.
- 지연이나 버스 놓침으로 연결이 달라지면 다음 차량 및 대체 경로를 다시 제안합니다.
- 위치는 이동 진행 상태를 보조합니다. 정류장 반경 30m 진입은 알림의 필수 조건이 아닙니다.
- iOS, Android, Web App을 목표로 하며 플랫폼별 알림 지원 범위는 별도 검증합니다.

## 경로 예시

| 후보 | 구간 |
|---|---|
| 환승 1 | A → a 버스 → B → b 버스 → D |
| 환승 2 | A → c 버스 → C → d 버스 → D |
| 직행 | A → e 버스 → D |

a·b·c·d·e 각각의 도착 시각과 이후 차량을 고려합니다. 첫 버스를 빨리 타더라도 환승 대기가 길면 직행 또는 다른 환승 경로가 더 빠를 수 있습니다. 실시간 정보와 시간표·배차간격 추정은 구분해 표시합니다.
